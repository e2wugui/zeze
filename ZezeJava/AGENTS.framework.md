# ZezeJava 框架维护

适用于明确修复、扩展或重构框架的任务；普通业务开发遵循 [AGENTS.app.md](AGENTS.app.md)。

- 从具体问题、公开契约和调用路径出发，区分框架缺陷、生成问题与应用误用。
- 保持常规应用路径简单、默认行为可预测；特殊入口说明适用条件及其绕过的保证。
- 修改时核对事务重试/回滚、table 与 Bean 生命周期、线程与提交时机、协议派发，避免局部修复破坏整体语义。
- 优先改善指南、命名和安全默认值。反复诱导错误且后果明显的接口，可考虑弃用或收紧；兼容性变化须说明收益、迁移成本与迁移办法。
- 生成问题修改生成器，按根 [AGENTS.md](../AGENTS.md) 发布并重生成；不手改生成文件，不提交 `Gen.exe`。
- 公开用法变化时同步更新相关指南和示例；按影响范围验证，只报告实际执行的检查。
