# ZezeJava 应用开发

Zeze 是限定应用框架：沿既定入口填写业务逻辑，不把所有公开 API 当作可任意组合的应用接口。

## 常规路径

- 在 XML 定义 bean、protocol、table，生成代码，在业务源码实现模块与 `Process*`；不手改生成文件。
- 保持默认事务和派发方式，在当前事务内通过生成的 table 访问数据。
- 事务可能重试或回滚；任务、消息等副作用使用事务感知入口。
- 异步任务优先用 `TaskSpec`，在线通知优先用 `OnlineSpec.send`；`Now` 入口会立即执行。
- 持久定时器在事务内调用 `Timer.schedule`；框架已处理提交后安装，无需再包一层 `whileCommit`。
- 不跨事务或异步边界持有托管 Bean；传主键并重新读取，或传独立快照。

## 扩展边界

常规业务逻辑和普通 Java 工具自主实现；已有扩展规则覆盖或任务明确授权的能力，按适用条件使用。

改变事务/派发方式、采用弱一致性读取、绕过提交时机立即执行副作用，或修改框架时，先核对扩展规则；规则未覆盖且无明确授权，说明必要性与语义变化并确认。
